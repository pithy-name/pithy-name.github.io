The architecture is the privacy model

  • Local-first, deterministic-first. Parsing, routing, tagging, linking, and rendering are plain scripts — zero tokens, zero upload. The LLM is reserved for the fuzzy bits and judgment calls.
  • Hybrid retrieval. Local embeddings + keyword search (BM25) fused by reciprocal-rank scoring, with metadata filters, over 10,000+ notes — and evaluated against real retrieval questions.

The public subset

Pieces are gradually being carved out, generalized, and published as standalone tools:

  • notion-to-obsidian — the ingest converter, already public.
  • The redaction pass — deterministic pseudonymization, under MIT license.
  • The skills library — reusable AI-workflow definitions, on the same path.
