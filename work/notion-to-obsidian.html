notion-to-obsidian

A converter that reconstructs Notion's database format — properties and body — as plain, portable markdown. Public, MIT-licensed, and paranoid about losing your files.

Repository: github.com/pithy-name/notion-to-obsidian

The problem

Notion's export gives you your data back in a shape only Notion loves: HTML and CSV with hashed filenames, database properties divorced from page bodies, and links that point at a workspace you're trying to leave. If years of your working life live in those databases, "export" is where the real migration work starts.

This tool reconstructs the database format — properties rejoined to their page bodies — and emits plain markdown with YAML frontmatter: readable in Obsidian, or in any editor, forever. Plain text is the only format with a guaranteed future.

The design discipline

The converter's real feature isn't conversion — it's accounting. Migration tools fail quietly, and you discover the missing files years later when you need them. So the rules are absolute:

  • No silent drops. Every file the tool touches produces exactly one manifest entry — a positive action, or an explicit skip with a reason. A file in the totals with no manifest line is treated as a bug, not a rounding error.
  • Idempotent re-runs. Run it twice, get the same vault — re-runs update rather than duplicate, so a failed batch is a resume, not a cleanup job.
  • The manifest is provenance. Months later, "where did this note come from and when" has an answer you can grep.

These rules were earned, not theorized — the tool was built to move years of my own records, and it's the same discipline I've applied to every bulk operation since: if a script processed a thousand files, it owes you a thousand receipts.
