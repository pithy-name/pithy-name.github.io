notion-to-obsidian

A converter that reconstructs Notion's database format — properties and body — as YAML frontmatter + markdown. Public, MIT-licensed.

Repository: github.com/pithy-name/notion-to-obsidian

The problem

Notion's export gives you your data back in an infuriating shape: HTML and CSV with hashed filenames, database properties divorced from page bodies, and links that point at a workspace you're trying to leave.

This tool reconstructs the database format — properties rejoined to their page bodies — and emits plain markdown with YAML frontmatter: readable in Obsidian, or in any editor.

Status

Public and working; packaging for a proper pip install is in progress.

Part of the Scriptorium public-subset roadmap — the ingest layer, generalized and released.
